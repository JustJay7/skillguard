# Native receipt-agent workflow

Run `make receipt-agent-workflow` after the documented local Linux/native dependencies are installed. It starts only the dedicated `sgtrace-clean` VM, uses the retained real response pack identified by `results/receipt-agent-live-latest.json`, and makes zero fresh inference requests. It runs native Harbor's scripted fake-key preflight in OpenShell, replays the unchanged response pack in Docker and OpenShell under independent Sysdig capture, archives checked evidence, recomputes the conservative decision, and stops the VM. No API key is loaded by this workflow.

The latest actual result is saved in `results/receipt-agent-workflow-latest.json`. The diagnostic passes only when both native executions and evidence finalizers succeed. Passing this orchestration is not a receipt-domain pass or protection metric.
